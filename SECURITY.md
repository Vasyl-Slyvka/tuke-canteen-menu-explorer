# Security policy

## Supported version

The latest release on the `main` branch receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature. Do not publish
credentials, private TUKE account data, or proof-of-concept payloads in a
public issue.

## Data and access boundaries

This project reads only the public menu pages. It does not authenticate to the
TUKE ordering system, submit orders, store cookies, or request personal data.
